## 项目简介

本项目设计并实现了一套面向高校宿舍场景的 **智能门锁系统**。系统以 **STM32F103C8T6** 单片机为核心控制器，集成了 **指纹识别、RFID 刷卡、矩阵键盘密码输入** 三种独立的身份认证方式，并通过 **ESP8266-01S WiFi 模块** 接入 **OneNET 云平台**，实现开锁记录的远程上报与门锁状态的远程监控。

系统具备管理员模式，支持指纹录入/删除、IC 卡授权/注销、用户密码修改、开锁日志查询等功能；同时内置防暴力破解机制（连续 5 次错误触发 30 秒锁定+声光报警），可有效提升宿舍门禁的安全性和管理效率。

> 📎 本仓库包含完整的 Keil 工程源码、硬件驱动、MQTT 协议封装及 OneNET 物模型解析代码。

## 主要功能特性

| 功能模块             | 详细说明                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------- |
| 🔐 三种开锁方式      | 指纹 (AS608) / RFID 卡 (RC522) / 密码 (4×4 矩阵键盘)                                         |
| 👨‍💼 管理员模式        | 长按 `#` 进入，支持指纹增删、IC 卡授权/注销、管理员/用户密码修改、查看操作日志                |
| 📟 人机交互          | 0.96 寸 OLED 显示系统状态、操作提示；蜂鸣器+LED 提供成功/失败/报警反馈                        |
| ☁️ 远程监控          | 基于 ESP8266 + MQTT 连接 OneNET 云平台，实时上报开锁记录（时间、方式、用户ID）及门锁状态       |
| 🔒 安全防护          | 任一认证方式连续错误 5 次 → 锁定 30 秒 + 声光报警 + 云端报警事件上报                          |
| 💾 本地存储          | AT24C02 存储管理员密码、指纹 ID 列表、授权卡号列表、开锁日志（10条循环覆盖）                  |
| ⏱️ 实时时钟          | DS1302 为开锁记录提供准确时间戳                                                              |
| 🔌 继电器控制        | 验证通过后驱动电磁锁舌，开锁 1~2 秒后自动复位                                                |

## 软件架构

- **IDE**：Keil μVision 5

- **云平台**：OneNET（MQTT 协议）
- **手机端**：微信小程序

### 关键软件流程

1. **初始化**：外设（GPIO、UART、SPI、I2C）→ 指纹模块握手 → RC522 校准 → OLED 显示 → 连接 WiFi → 接入 OneNET。
2. **主循环**：
   - 检测指纹触摸中断 → 调用指纹验证。
   - 轮询 RC522 → 识别到卡则进行 UID 比对。
   - 扫描键盘 → 密码开锁 / 长按 `#` 进入管理员菜单。
3. **管理员菜单**：指纹增删、IC 卡增删、修改密码、查看日志。
4. **安全机制**：连续错误计数器 → 达阈值（5次）→ 锁定 + 报警 + 上报云端。
5. **远程监控**：开锁事件（时间/方式/ID）→ JSON 封装 → MQTT 发布到 OneNET → 小程序实时展示。
